# Nordvik Tracking Demo

Demo site for a GTM and GA4 tracking implementation: data layer events, UTM tests and (next) a server-side purchase. **Fictional brand, no real products, prices or orders, no personal data.**

*Status: draft. Screenshots and findings to be added.*

- Live site: https://yvettedzs.github.io/nordvik-tracking-demo/
- Tracking plan: [`docs/tracking_plan.md`](docs/tracking_plan.md)
- Setup guide: [`docs/gtm_setup_guide.md`](docs/gtm_setup_guide.md)

## What is real and what is not
- Real: GTM container, GA4 property, the data layer events and their parameters, the test traffic I generated.
- Not real: the company, products, prices, orders and customers. Server-side tracking, conversion APIs and ad-platform pixels are not part of this demo.
